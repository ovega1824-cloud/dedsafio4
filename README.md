# Desafío 4 (Forge 1.20.1)

Mod con ruletas, momentos "revil", menús de misiones, animaciones de muerte y revivir, tótems, objetos y cambios de dificultad. Todo se puede activar por menú, por ítem o por comandos.

## Descargar el .jar
1. Sube este proyecto a un repositorio de GitHub (rama `main`).
2. Entra a la pestaña **Actions**: se compila solo (si no, ejecuta "Compilar mod" con *Run workflow*).
3. El .jar queda en **Releases** (`desafio4-1.0.0.jar`) y también como artefacto del workflow.
4. Ponlo en la carpeta `mods` de Forge 1.20.1 (47.x).

## Comandos
Usa `/d4` (con autocompletado; `/d4 menu` abre el panel) para ver todos. Panel principal: ítem "Panel" o la tecla configurada en Controles.
